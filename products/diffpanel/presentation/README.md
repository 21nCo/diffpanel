# @diffpanel/presentation

Framework-neutral chapter navigation, review counters, conservative repeated
change grouping, and safe Mermaid diagram policy for Diffpanel review UIs.

```ts
import {
  chapterLabels,
  groupFiles,
  diagramSourceError,
} from "@diffpanel/presentation";
```

The package is browser-safe. Requires Node.js 22.13 or newer.
